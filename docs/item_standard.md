# มาตรฐานการทำไอเทม (Emberfall)

## 1. หลักการ
- **ทำไอเทม 1 ครั้ง ใช้ได้ทุกอาชีพ** — ทุกอาชีพใช้ตัวฐาน Novice ชาย/หญิงร่วมกัน ความต่างของอาชีพมาจากอุปกรณ์ที่สวม
  ไอเทม 1 ชิ้น = ภาพ 1 ภาพ = โมเดล 1 ตัว = เรนเดอร์ 2 ชั้นภาพ (ตัวฐานชาย + ตัวฐานหญิง) ทำอัตโนมัติ
- **จำกัดอาชีพเป็นแค่ข้อมูล** (`class_only`) ไม่ต้องทำภาพแยก
  กติกา: อาวุธ ธนู และโล่ของอาชีพ → ใส่ได้เฉพาะอาชีพนั้น · หมวก ผ้าคลุม ปีก ของ Novice และแฟชั่น → ใส่ได้ทุกอาชีพ
- **แหล่งข้อมูลเดียว** คือ `tools/item_catalog.csv` — เกมอ่านจาก `data/items.js` ที่สร้างจากไฟล์นี้ ไม่ต้องแก้โค้ดเกม

## 2. ข้อมูลไอเทม (คอลัมน์ใน `tools/item_catalog.csv`)
| คอลัมน์ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `id` | รหัสภาษาอังกฤษ ตัวเล็ก ใช้ `_` คั่น (เป็นชื่อไฟล์ภาพด้วย) | `iron_helmet` |
| `game_key` | ชื่อไอเทมในเกม (ไอเทมเดิมใช้ชื่อเดิม เพื่อไม่ให้เซฟพัง) | `หมวกเหล็ก` |
| `name_th` | ชื่อไทยที่แสดง | `หมวกเหล็ก` |
| `slot` | ตำแหน่งติดตัวละคร (ดูข้อ 3) | `head` |
| `game_slot` | ช่องสวมใส่ในเกม | `head` |
| `class` | อาชีพที่ออกแบบมาให้ (ใช้จัดหมวด) | `knight` |
| `class_only` | ว่าง = ทุกอาชีพ · ใส่ชื่ออาชีพ = ใส่ได้เฉพาะอาชีพนั้น | `knight` |
| `tier` | `starter` `common` `rare` `epic` `legend` `fashion` | `common` |

| `prompt` | คำสั่งสำหรับ Gemini | |

## 3. ช่องและการติดตั้ง
| `slot` | ช่องในเกม | ติดกับ | ลำดับวาด | ทิศทางในภาพ |
|---|---|---|---|---|
| `head` | หมวก | กระดูกหัว (วาดทับผม) | บนสุด | ตั้งตรง มองจากหน้า ช่องใส่หัวอยู่ล่าง |
| `hand_r` | อาวุธ | มือขวา | 3 | แนวตั้ง ด้ามจับอยู่ล่าง ปลายชี้ขึ้น |
| `hand_l` | อาวุธ (ธนู) | มือซ้าย | 3 | แนวตั้ง จับตรงกลาง |
| `arm_l` | โล่ | แขนซ้าย | 2 | ตั้งตรง มองจากหน้า |
| `back` | ผ้าคลุม | หลัง | 1 | ตั้งตรง มองจากด้านหลังตามที่สวม |

ส่วนที่อยู่หลังตัวละครถูกซ่อนอัตโนมัติ (ตัวละครเป็นตัวบังตอนเรนเดอร์)

## 4. สเปคภาพจาก Gemini
- อัปโหลด `images/tripo/ranger_front.png` เป็นต้นแบบลายเส้นทุกครั้ง
- ไอเทม 1 ชิ้นต่อ 1 ภาพ ไม่มีตัวละคร หัว หรือมือ
- เห็นครบทั้งชิ้น อยู่กลางภาพ ตามทิศทางในข้อ 3
- พื้นหลังสีขาวเรียบ ไม่มีลายตารางหมากรุก ไม่มีเงา ไม่มีตัวหนังสือ
- บันทึกเป็นไฟล์ชื่อ `<id>.png` หรือ `<id>.jpg` ใน `images/items/`
- **หมวก/ฮู้ด ต้องเห็นจากด้านบนเล็กน้อย** ให้เห็นความลึกและช่องใส่หัวด้านใน — ภาพตรงหน้าแบนสนิท AI จะสร้างเป็นแผ่นแบน
  (สคริปต์เตือน `WARNING flat item` ถ้าความลึกน้อยกว่า 20% ของความกว้าง) · ที่คาดผม หู เขา โบว์ ใช้มุมตรงหน้าได้ เพราะของจริงบางอยู่แล้ว
- ไอเทมสีขาว (หมวกเชฟ ขนสัตว์ขาว) ใช้ได้ — สคริปต์ทำสีขาวให้เทาลงเฉพาะตอนสร้างรูปทรง เพราะ Hunyuan มองของขาวบนพื้นขาวไม่เห็น

โครง prompt:
```text
A single <ไอเทม> as a game item, same anime art style as the uploaded image, thick dark outlines, soft cel shading. Only the item, no character, no head, no hands. <ทิศทางตามช่อง> Plain solid white background, no checkerboard pattern, no shadow, no text.
```

## 5. ขั้นตอน
1. เพิ่มแถวใน `tools/item_catalog.csv` (ไอเทม 100 ชิ้นแรกมีอยู่แล้ว ดู `docs/item_prompts.md`)
2. สร้างภาพใน Gemini แล้ววางที่ `images/items/<id>.png`
3. สั่ง
   ```bash
   python tools/build_items.py
   ```
   สร้างเฉพาะภาพใหม่ (ไอเทมละ ~4 นาที) แล้วเขียน `data/items.js` ใหม่ — เปิดเกมก็เห็นไอเทมทันที
4. ถ้าขนาด/ตำแหน่งยังไม่พอดี: ใส่ค่าในคอลัมน์ `fit_size` `fit_sink` `fit_rot` `fit_offset` ของไอเทมนั้นใน `tools/item_catalog.csv`
   แล้วสั่ง `python tools/build_items.py --refit <id>` (ไม่สร้างโมเดลซ้ำ ~1 นาที)
   - หมวกทั่วไป: ค่าเริ่มต้น (`sink 0.2`, `size 1.0`) · ฮู้ดคลุมทั้งหัว: `sink ~0.95` `size ~1.3` · ที่คาดผม: `sink ~0.45`
5. ต้องการรูปใหม่: วางภาพทับไฟล์เดิม แล้วสั่ง `python tools/build_items.py --force <id>`

## 6. แนวทางค่าสถานะตาม tier
| tier | อาวุธ ATK | หมวก/โล่ DEF | ราคา |
|---|---|---|---|
| starter | 3–6 | 1–3 | 60 |
| common | 8–16 | 3–9 | 250 |
| rare | 16–24 | 5–14 | 600 |
| epic | 24–30 | 8–16 | 1,500 |
| legend | 36–45 | 12–22 | 4,000 |
| fashion | เล็กน้อย | เล็กน้อย | 800 |

## 7. สิ่งที่ยังไม่ครอบคลุม
- ชุดเกราะ/เสื้อผ้าทั้งตัว — จะทำเป็น "ชุดเต็มตัว" แยกต่างหาก
- ไอเทมยังไม่ถูกใส่ใน drop ของมอนสเตอร์หรือร้านค้าอัตโนมัติ
